---

## 🌟 Features

- **Task Management**: Easily add new tasks to your list.
- **Mark as Completed**: Click on any task to mark it as done with a strikethrough effect.
- **Delete Tasks**: Remove tasks you no longer need with the '×' button.
- **Input Validation**: Prevents adding empty tasks to keep your list clean.

## 💻 Tech Stack

- **HTML5**: Semantic structure of the application.
- **CSS3**: Custom styling, clean UI layout, and responsive design.
- **JavaScript (ES6+)**: DOM manipulation and event handling for interactive features.
