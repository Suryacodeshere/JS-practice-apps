## 🌟 Features

- **Real-Time Data**: Get the latest weather updates for any city globally.
- **Detailed Metrics**: Displays accurate temperature (°C), humidity levels (%), and wind speed (km/h).
- **Dynamic Icons**: The weather icon updates automatically based on the current weather condition (Clear, Clouds, Rain, Drizzle, Mist).
- **Error Handling**: Friendly error message when a city is not found.

## 💻 Tech Stack

- **HTML5**: Semantic structure of the application.
- **CSS3**: Custom styling, flexbox layouts, and responsive design.
- **JavaScript (ES6+)**: Asynchronous API fetching (`fetch`, `async/await`) and DOM manipulation.
- **API**: [OpenWeatherMap API](https://openweathermap.org/) (Geocoding API & Current Weather Data API).

   ```bash
   git clone https://github.com/yourusername/JS-practice-apps.git
   ```
2. **Navigate to the project directory**:
   ```bash
   cd "JS practice apps/weather app"
   ```
3. **Open the app**:
   Simply double-click the `index.html` file to open it in your browser, or use the **Live Server** extension in VS Code.

## 🔑 API Key Note

This project uses the OpenWeatherMap API. If you plan to fork this project and use it in production, it is highly recommended to sign up at [OpenWeatherMap](https://openweathermap.org/) to get your own free API key and replace the `apiKey` variable in `script.js`.
